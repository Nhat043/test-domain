# Vercel domain test

Mini project để bạn deploy nhanh lên Vercel và test domain mới.

## Cách dùng

1. Tạo project mới trên Vercel.
2. Chọn repo này.
3. Set `Root Directory` thành `vercel`.
4. Deploy.

## Nội dung

- `index.html`: landing page test domain.
- Không cần build step.
- Không cần dependency cài thêm.
